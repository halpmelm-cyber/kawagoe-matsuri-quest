# 今福囃子連中 × 六軒町 祭りクエスト V3

今福囃子連中と六軒町・三番叟の山車を中心にした、スマートフォン／PC向けの川越まつり学習ゲームです。

## 公開
GitHub Pages の `main` / `/ (root)` で公開できます。

## 主なカスタマイズ
- 今福囃子連中 × 六軒町をゲームの中心に変更
- 三番叟の山車を図鑑の主役に追加
- 芝金杉流と今福囃子の説明を追加
- 1888年の六軒町山車新造と今福囃子の関係を追加
- 1961年、1977年、2005年、2016年の歴史を追加
- 今福×六軒町専用クイズを追加
- 黒・金・赤を基調にUIを調整

※文化財・歴史情報は川越市公式情報を参照して構成しています。
