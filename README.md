# 川越まつりクエスト V2

川越まつりを「遊びながら学ぶ」ためのブラウザゲーム基盤。

## V2の追加機能
- 町/コース選択
- 山車を選んで祭りへ出発
- 学習クイズ
- 囃子リズムゲーム
- 曳っかわせタイミングゲーム
- XP / 祭り札 / レベル
- 山車・囃子図鑑
- 歴史年表
- データとゲーム処理を分離

## カスタマイズ
`data.js` の以下を編集:
- TOWNS = 町・コース
- FLOATS = 山車・囃子などの図鑑
- HISTORY = 歴史
- QUIZ = 問題

ゲームシステムは `app.js`、デザインは `styles.css`。
