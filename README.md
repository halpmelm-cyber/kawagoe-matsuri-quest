# 川越まつりクエスト V6
スマホ・PC対応のドット探索＋学習クイズ＋お布施ガチャ版。

## V6
- ドットRPG風の街
- NPCと会話
- 5つの探索スポット
- クイズ初回正解でお布施100
- 復習正解でもお布施20
- お布施100で1回 / 900で10回ガチャ
- SSR / SR / R / N のコレクション
- XP・レベル・探索記録・ガチャ所持数を自動保存
